# Focus Hub

Модульный CLI-инструмент для управления временем, задачами и привычками.

**Focus Hub** — персональная утилита продуктивности, построенная вокруг техники Pomodoro 
В будущем расширенная функциями управления задачами, отслеживания привычек и личной рефлексии. 

## Функциональность

### Функции готовые к работе
- **Pomodoro Timer** — сеансы работы с настраиваемыми интервалами
- **To-Do List** — управление задачами рядом с таймером
- **Habit Tracker** — отслеживание и развитие привычек
- **Система плагинов** — расширения для собственных модулей в один файл

### Функции в разработке
- **Diary** — размышления о прогрессе и дне
- **Экспорт данных** — сохранение в JSON или синхронизация с Obsidian

## Плагины

Плагины — это обычные Python-модули в каталоге `extensions/`. Они
обнаруживаются и загружаются автоматически при старте и появляются в главном меню.

```python
# extensions/my_tool.py
from core.plugins import register

@register(name="my tool", key="m", description="Does something neat")
def run(width):
    ...
```

- `name` — подпись в меню
- `key` — однобуквенный символ, которым плагин запускается
- `description` — необязательный; по умолчанию берётся из docstring функции

Обработчик получает текущую ширину терминала `width` и может сохранять
состояние через `core.storage` (`load` / `save`). Встроенные функции
(pomodoro, to-do, настройки) регистрируются так же через `core.plugins.load_builtins()`.

## Разработка

Запуск тестов:

```bash
pip install -r requirements.txt -r requirements-dev.txt
python -m pytest
```

Отчёт о покрытии (та же команда, что в CI):

```bash
python -m pytest --cov=core --cov=extensions --cov=cli --cov-report=term-missing
```
