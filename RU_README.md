# Focus Hub

Модульный CLI-инструмент для управления временем, задачами и привычками.

**Focus Hub** — персональная утилита продуктивности, построенная вокруг техники Pomodoro 
В будущем расширенная функциями управления задачами, отслеживания привычек и личной рефлексии. 

## Функциональность

### Функции готовые к работе
- **Pomodoro Timer** — сеансы работы с настраиваемыми интервалами
- **To-Do List** — управление задачами рядом с таймером

### Функции в разработке
- **Habit Tracker** — отслеживание и развитие привычек
- **Diary** — размышления о прогрессе и дне
- **Экспорт данных** — сохранение в JSON или синхронизация с Obsidian
- **Расширяемость** — официальная система плагинов для пользовательских модулей

## Видение

Начните с таймера. Расширяйте по мере необходимости. Никакого лишнего — только то, что используете.

## Статус

Ранняя разработка. CLI на первом плане, GUI в планах.
