
# Focus Hub

A modular CLI productivity suite for managing your time, tasks, and habits.

**Focus Hub** is a personal productivity tool built around the Pomodoro technique, 
extended with task management, habit tracking, and personal reflection capabilities. 
It's designed to grow with you—from a focused timer to a complete productivity system.

## Run

step 1: clone repository 
`git clone https://github.com/r3ven000/focus-hub.git`

step 2: run
`cd focus-hub/`
`python -m cli.main`

## Features

- **Pomodoro Timer** — Time-boxed work sessions with configurable intervals
- **To-Do List** — Manage tasks alongside your Pomodoro sessions
- **Habit Tracker** — Build and monitor long-term habits
- **Diary** — Reflect on your progress and day
- **Data Export** — Save your data as JSON or sync with Obsidian
- **Extensible** — Official plugin system for custom modules

## Vision

Start with a focused timer. Expand based on your needs. No bloat—only what you use.

## Status

Early development. CLI-first, GUI coming soon.
